# Eco-Risorse Italia

Serious game gestionale sull'impresa del riciclo, ambientato a San Ginesio e legato ad Agenda 2030.

## Gruppo

**I Riciclatori**

## Studenti

- Giulia Bordi
- Luca Paradisi
- Leonardo Fioravanti
- Lorenzo Funari

## Tema

Il giocatore gestisce una nuova azienda di economia circolare, prendendo decisioni annuali che modificano tre indicatori: budget, ambiente e persone. Se un indicatore arriva a zero, l'impresa chiude.

## Pubblicazione

La versione pubblicata usa la build statica contenuta nello zip originale, ripulita da dipendenze e file di sviluppo.
