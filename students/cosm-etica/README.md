# Cosm-Etica

**Gruppo:** Cosm-Etica  
**Tema:** cosmetici biologici, profitto, pianeta, persone, cruelty-free, energia pulita

Serious game gestionale in cui il giocatore guida un'azienda europea di cosmetici biologici. Le decisioni strategiche incidono su cassa, impatto ambientale, clima sociale e credibilita etica del brand.
