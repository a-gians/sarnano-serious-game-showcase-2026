# Eudaimonia Corp

**Gruppo:** MND  
**Autori:** Edoardo Compagnucci, Federica Marini, Davide Bruni  
**Tema:** startup di supporto psicologico, SDG 8, SDG 12, profitto, persone, pianeta

Videogioco manageriale e narrativo in cui il giocatore interpreta il CEO di Eudaimonia Corp, una startup di supporto psicologico. Le scelte chiedono di bilanciare fatturato, benessere delle persone e sostenibilita energetica.
